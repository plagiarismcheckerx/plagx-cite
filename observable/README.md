# Observable notebook

The cells of the [Plagx Cite Observable notebook](https://observablehq.com/@plagiarismcheckerx/plagx-cite), in order. Paste each one into a new cell on observablehq.com.

The notebook loads the published [plagx-cite npm package](https://www.npmjs.com/package/plagx-cite) from jsDelivr. To update it, change the version number in cell 2.
